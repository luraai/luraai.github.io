개인정보 처리방침

시행일: 2026년 10월 17일

Pawdiaro는 계정이 없고, 일기·사진·케어 기록을 LuraAI 서버로 보내지 않아요. 기록은 이 기기 안에만 저장되고, 광고·분석·추적 SDK도 쓰지 않아요.

1. 수집하는 정보

LuraAI(이하 “회사”)는 Pawdiaro(이하 “앱”)를 통해 개인정보를 수집하지 않아요.

  • 회원가입과 로그인이 없어요.
  • 이름, 이메일, 전화번호, 위치 정보를 묻거나 수집하지 않아요.
  • 광고, 분석, 추적용 SDK를 넣지 않았고, 서드파티 SDK도 쓰지 않아요.
  • 앱에는 회사 서버로 데이터를 보내는 기능이 없어요.

2. 이 기기에 저장되는 정보

앱이 동작하려면 아래 정보가 사용자의 기기 안에 저장돼요. 회사는 이를 볼 수 없어요.

  • 반려동물 프로필(이름, 종, 생일·입양일, 사진, 이름표 색)
  • 일기(글, 사진, 기분, 작성자 이름), 일기장
  • 케어 일정과 완료 기록(접종·구충·약·검진 등), 체중 기록, 사육장·수조 온도·습도 기록
  • 설정(알림 시각, 단위 등)과 구독 상태

사진은 저장할 때 위치 정보(GPS)를 포함한 메타데이터를 지우고 크기를 줄여 보관해요.

3. 알림

케어 알림은 기기 안에서 예약하는 로컬 알림이에요. 알림 내용이 서버를 거치지 않아요. 알림 권한은 기기 설정에서 언제든 끌 수 있어요.

4. AI 기능

일기 초안, 월간 요약, 일정 문장 인식은 기기 안에서 처리돼요. 지원 기기에서는 Apple의 온디바이스 모델(Foundation Models)과 Vision을 쓰고, 입력한 글이나 사진은 기기 밖으로 나가지 않아요. 회사나 제3자의 AI 서버를 쓰지 않아요.

선택 기능: Apple Intelligence가 없는 기기에서 사용자가 직접 ‘AI 모델 관리’에서 작은 오픈소스 모델을 내려받을 수 있어요. 이때 모델 파일을 Hugging Face(huggingface.co)에서 내려받는 요청만 이뤄지고, 일기·사진 등 사용자의 기록은 전송되지 않아요. 내려받기는 사용자가 동의한 뒤에만 시작돼요.

5. 결제

구독과 평생 이용 결제는 Apple App Store가 처리해요. 앱은 구매 상태만 StoreKit으로 확인하고, 카드 정보나 Apple ID 정보를 받지 않아요.

6. 공유·내보내기

사용자가 직접 ‘공유’나 ‘파일에 저장’을 누를 때만 일기 PDF, 병원 제출용 요약 PDF, 올해의 회고 이미지를 만들어 iOS 공유 시트로 넘겨요. 파일은 기기 안에서 만들어지고, 어디로 보낼지는 사용자가 정해요.

7. Siri·단축어와 Apple Watch

Siri/단축어의 답변과 Apple Watch의 ‘오늘 할 케어’는 기기 안에 있는 기록을 바탕으로 만들어져요. Siri 음성 처리는 Apple의 정책을 따라요.

8. 데이터 삭제와 보관

앱의 가족 탭 › 전체 삭제로 기록과 설정을 한 번에 지울 수 있고, 앱을 삭제해도 기기의 앱 데이터가 지워져요. 기기의 iCloud 백업을 켜 두었다면 백업에 앱 데이터가 포함될 수 있으며, 이는 사용자의 Apple ID 설정에 따라요. ‘데이터 내보내기’로 사본을 받아 둘 수도 있어요.

9. 아동

앱은 아동의 개인정보를 수집하지 않아요. 앱의 어떤 기능도 연령을 묻거나 개인정보를 요구하지 않아요.
