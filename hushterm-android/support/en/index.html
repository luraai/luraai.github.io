Getting started

  1. Open Hosts and tap "Try it without a server" to explore on a simulated server, or tap + to add an SSH host.
  2. Choose password or key authentication. Confirm the host key the first time you connect.
  3. Type in the terminal; the key bar above the keyboard switches between shell, full-screen apps and tmux.

Common questions

A command is held with a warning. The risky-command guard stops commands such as rm -rf, dd or chmod -R 777 before they are sent. You can still send them after reading the explanation.

Connection fails. Open the host's menu and choose Diagnose. It checks DNS, TCP, host key, authentication and shell, step by step.

The host key changed. Hushterm blocks the connection. Verify the new fingerprint with the server's owner before accepting it.

Server check. In a connected terminal open the ⋯ menu and choose Server check (or long-press a host in the list). It sends only read-only commands, shows what it found with the lines behind it, and shows what changed since the last check on that host. The picker also lets you create your own checks from read-only commands; anything that writes is refused. Use the launcher shortcut "Server check" to jump straight to the last host's check.

Practice Linux. Hosts > the box icon > Linux practice course. Each exercise opens a fresh virtual Ubuntu server with a goal and hints; it is free, works offline and keeps your progress on the device only.

Try an agent without a server. On the demo server type agent, then open the Sessions tab to approve or deny the simulated agent and see the history.

Sessions in the background. While sessions are open, a notification keeps them connected. Close sessions from the Sessions tab or use "Disconnect all" in the notification.

Agent control (Claude Code, Codex; basic Gemini CLI and aider). The Sessions tab shows working, waiting for approval, waiting for input or failed, with a history of every request and decision. Pro adds Approve/Deny in notifications and on the watch, plus finished and failed alerts. Risky or prod requests must be reviewed in the app.

AI is unavailable. Model-based AI needs a device with an on-device model (AICore). Rule-based explanations work on every device.

Backup and new phone. Hosts, snippets, port forwards and settings are in Android Auto Backup. Passwords and private keys are not; export a backup file or re-enter them. Settings > Backup has export and import.

Subscription. Manage or cancel in Google Play > Subscriptions. Use "Restore" on the Pro screen after reinstalling.

Wear OS. Install Hushterm on the watch from Google Play on your phone. The watch shows hosts and agent status, runs a basic server check (not on prod hosts) and safe snippets, and handles approvals; it requires the phone app.
