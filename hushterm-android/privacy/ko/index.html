Hushterm 개인정보 처리방침

최종 수정일: 2026년 10월 16일 · 게시자: Kang Seok Ju (luraai.io) · 문의: contact@luraai.io

English 한국어

1. 요약

Hushterm은 SSH · SFTP 클라이언트입니다. 계정, 개발자 서버, 분석, 광고, 추적이 없으며 개발자는 사용자의 데이터를 수집하지 않습니다.

2. 기기에 남는 정보

  • 호스트(이름, 주소, 포트, 사용자 이름, 메모, 폴더, 태그), 포트 포워딩, 스니펫, 명령 기록, 설정은 기기의 앱 전용 저장소에 저장됩니다.
  • 비밀번호와 개인 키는 Android Keystore의 키로 암호화합니다. "하드웨어 보호 키"로 만든 키는 보안 하드웨어 밖으로 나오지 않습니다.
  • 터미널 출력은 세션이 열려 있는 동안 메모리에만 있으며 앱이 디스크에 기록하지 않습니다.

3. 정보가 이동하는 곳

  • 사용자의 서버: 접속하면 사용자가 지정한 서버로 SSH를 통해 인증 정보와 입력한 명령을 보냅니다. 이 통신은 기기와 해당 서버 사이에서만 이루어집니다.
  • Google Play: 구매와 구독은 Google Play 결제가 처리하며 결제 정보는 개발자에게 전달되지 않습니다.
  • Wear OS: 시계 앱을 쓰면 호스트 이름, 스니펫 제목, 승인 대기 요청이 Wearable Data Layer로 휴대전화와 시계 사이에서만 오갑니다. 개발자 서버를 거치지 않습니다.
  • 백업: Android 자동 백업이 호스트 목록, 포트 포워딩, 스니펫, 설정을 Google 계정에 백업할 수 있습니다. 비밀번호, 개인 키, 구매 캐시는 제외됩니다. 직접 백업 파일로 내보낼 수도 있습니다.

4. AI 기능

명령 제안, 오류 분석, 요약, 접속 진단, 음성 입력은 기기 안에서 동작합니다. Android가 제공하는 온디바이스 모델(AICore)이 있으면 이를 쓰고, 없으면 내장 규칙 엔진을 씁니다. Hushterm에는 제3자 AI SDK, AI API 키, 서버가 없으며 프롬프트, 터미널 출력, 오디오를 기기 밖으로 보내지 않습니다. 음성 입력은 마이크 권한을 허용하고 마이크 버튼을 눌렀을 때만 시스템의 기기 내 음성 인식을 사용합니다. Claude Code · Codex 같은 코딩 에이전트의 권한 질문은 사용자의 SSH 세션 안에서 감지할 뿐 해당 서비스에 접속하지 않습니다.

5. 권한

인터넷(서버 접속), 알림(승인 요청 및 백그라운드 세션 안내), 포그라운드 서비스(열린 세션 연결 유지), 마이크(음성 입력, 선택), 생체 인증(앱 잠금과 보호 키, 선택).

6. 아동

Hushterm은 개발자 도구이며 어린이를 대상으로 하지 않습니다.

7. 데이터 삭제

앱을 삭제하면 기기에 저장된 모든 정보가 삭제됩니다. 개발자 쪽에 보관하는 데이터가 없으므로 별도로 삭제할 것이 없습니다. Google 계정의 백업은 Google 설정에서 지울 수 있습니다.
