채움장
지원 English

개인정보 처리방침

시행일: 2026년 10월 9일 · English

채움장은 계정과 서버, 광고, 분석 도구가 없는 앱이에요. 문서와 기록은 이 기기에만 저장되고 LuraAI나 제3자에게 전송되지 않아요. 문서 자동 분류용 모델 파일을 내려받을 때만 인터넷에 연결돼요(동의한 경우에 한함).

1. 수집하는 정보

LuraAI(“회사”)는 채움장(“앱”)을 통해 개인정보를 수집하지 않아요.

  • 회원가입과 로그인이 없어요.
  • 이름, 이메일, 전화번호, 위치, 기기 식별자, 사용 기록을 요청하거나 수집하지 않아요.
  • 분석·추적·광고 SDK를 쓰지 않고, 제3자 SDK도 넣지 않았어요.
  • 사용자의 문서나 입력 내용을 회사 서버로 보내는 기능이 없어요.

2. 기기에 저장되는 정보

아래 정보는 앱이 동작하는 데 필요하며 이 기기 안에서만 보관돼요.

  • 작성한 계약서·서식 내용, 사업자 정보, 거래처
  • 도장 설정과 직접 그린(또는 사진에서 가져온) 서명 이미지
  • 가져오거나 스캔한 문서와 날인 이력, 문서에서 읽어 낸 텍스트(분류·검토용 캐시)
  • 장부(매출·매입) 내역, 영수증 사진, 앱 설정

앱을 삭제하면 함께 지워지고, 설정 › “모든 데이터 삭제”로 앱 안에서 직접 지울 수도 있어요.

3. 기기 권한

권한을 거부하면 해당 기능만 쓸 수 없어요.

권한사용 목적
카메라종이 문서 스캔, 영수증 촬영. 사진은 이 기기에만 저장돼요.
사진 보관함영수증이나 서명 사진을 직접 골라 가져올 때만 사용해요.

알림 권한은 요청하지 않아요.

4. 기기 안에서 실행되는 AI

AI 계약서 검토는 Apple Intelligence의 온디바이스 모델(Foundation Models)로 실행돼요. 검토할 문서의 텍스트는 기기 안에서만 처리되고 회사나 제3자에게 전송되지 않아요. 지원하는 기기와 iOS 26 이상, 한국어 지원이 필요해요.

문서 자동 분류는 오픈 모델(embeddinggemma-2, 약 310MB)을 기기에서 실행해요. 모델 파일은 앱을 실행한 뒤 사용자가 동의한 경우에만 Hugging Face에서 한 번 내려받아요. 내려받는 것은 모델 파일뿐이며 사용자의 문서나 정보는 업로드되지 않아요. 모든 파일 내려받기와 마찬가지로 요청한 서버(Hugging Face)는 접속 IP 주소를 볼 수 있어요. 모델은 설정에서 언제든 지울 수 있고, 기기 백업에는 포함되지 않아요.

5. 파일 내보내기와 백업

PDF·한글(HWPX)·워드(DOCX) 문서와 백업 파일(.chaeumbackup)은 사용자가 고른 위치(파일 앱, 공유 시트 등)에만 저장돼요. 백업 파일에는 작성한 문서 내용과 서명 이미지가 포함되며 암호화되지 않으니 보관과 공유에 주의해 주세요. 파일을 다른 곳으로 보내는 것은 사용자가 직접 선택한 경우에만 일어나요.

6. 결제

앱은 무료로 내려받고, 추가 기능(Pro)은 한 번 구매하는 평생 이용권(앱 내 구입, 구독 아님)이에요. 결제와 영수증 확인은 전적으로 Apple이 처리하며, 회사는 결제 정보나 Apple 계정 정보를 받지 않아요. 구매는 Pro 화면의 “구매 복원”으로 복원할 수 있어요.

7. 제3자 제공·광고·추적

개인정보를 수집하지 않으므로 제공하거나 판매할 정보가 없어요. 쿠키, 광고 식별자(IDFA), 앱 간 추적을 쓰지 않아요.

8. 어린이

채움장은 연령과 관계없이 누구의 개인정보도 수집하지 않아요.

9. 방침의 변경

방침이 바뀌면 위의 시행일과 내용을 갱신하고, 중요한 변경은 앱 업데이트 노트로 알려요.
