Pour commencer

Ajoutez le profil de votre enfant, puis choisissez une histoire intégrée ou racontez votre journée à la lune. Touchez Lecture pour écouter ; le minuteur baisse le son au coucher.

Les histoires IA ne sont pas disponibles sur mon appareil

Les histoires IA demandent un appareil compatible avec l'IA intégrée (Gemini Nano via AICore) avec le modèle téléchargé, ou un fichier de modèle IA importé avec Pro (Réglages › Modèles IA). Histoires intégrées, lecture et bibliothèque fonctionnent sur tous les appareils.

Restaurer ou résilier un achat

Réglages › Restaurer les achats. Pour résilier un abonnement, ouvrez Google Play › Paiements et abonnements › Abonnements.

Transférer les histoires vers un autre téléphone

Réglages › Exporter un fichier de sauvegarde, puis Importer un fichier de sauvegarde sur l'autre appareil. La sauvegarde automatique d'Android peut aussi restaurer vos données lors de la configuration d'un nouveau téléphone.

Signaler une histoire problématique

Ouvrez l'histoire, touchez ⋯ › Signaler un problème. L'histoire est masquée aussitôt ; vous pouvez aussi nous écrire.

Supprimer mes données

Réglages › Supprimer toutes les données.
