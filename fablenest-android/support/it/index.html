Per iniziare

Aggiungi il profilo del tuo bambino, poi scegli una storia integrata o racconta la giornata alla luna. Tocca Riproduci per ascoltare; il timer abbassa il volume prima di dormire.

Le storie IA non sono disponibili sul mio dispositivo

Le storie IA richiedono un dispositivo con IA integrata (Gemini Nano tramite AICore) con il modello scaricato, oppure un file di modello IA importato con Pro (Impostazioni › Modelli IA). Storie integrate, lettura e libreria funzionano su ogni dispositivo.

Ripristinare o annullare un acquisto

Impostazioni › Ripristina acquisti. Per annullare un abbonamento apri Google Play › Pagamenti e abbonamenti › Abbonamenti.

Spostare le storie su un altro telefono

Impostazioni › Esporta un file di backup, poi Importa un file di backup sull'altro dispositivo. Il backup automatico di Android può anche ripristinare i dati quando configuri un nuovo telefono.

Segnalare una storia problematica

Apri la storia, tocca ⋯ › Segnala un problema. La storia viene nascosta subito; puoi anche scriverci.

Eliminare i miei dati

Impostazioni › Elimina tutti i dati.
