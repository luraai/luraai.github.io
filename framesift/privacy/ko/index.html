개인정보 처리방침

최종 업데이트: 2026년 10월 18일

프레임시프트는 사진을 iPhone 안에서만 분석하고, 말로 찾는 검색도 iPhone 안에서만 해요. 계정도 서버도 없어요. 사진, 검색어, 스크린샷에서 읽은 글자는 기기 밖으로 나가지 않으며, 개인정보를 수집하지 않아요. Pro 사용자가 직접 시작하면 AI 모델 파일을 한 번 내려받아요(3항).

1. 수집하는 정보

LuraAI(“회사”)는 프레임시프트(“앱”)를 통해 어떤 개인정보도 수집·전송·공유하지 않아요. 회원 가입이 없고, 회사가 운영하는 서버가 없으며, 분석·추적·광고 SDK도 들어 있지 않아요. 앱이 인터넷을 쓰는 경우는 Apple을 통한 결제와, Pro 사용자가 직접 시작하는 AI 모델 내려받기(3항)뿐이에요.

2. 앱이 사진을 쓰는 방식

  • 사진 보관함 접근은 비슷한 사진·스크린샷·흐린 사진·큰 영상을 찾고, 날짜·유형·앨범·장면별로 모으고, 사용자가 확인한 사진을 ‘최근 삭제된 항목’으로 옮기거나 사용자가 만든 앨범에 추가하는 데 쓰여요.
  • 분석은 기기 안에서만 이뤄져요. Apple Vision 프레임워크가 iPhone에서 이미지 특징·선명도·장면 종류를 계산하고, 스크린샷 속 글자와 바코드를 읽어 영수증·티켓·인증번호 등으로 나눠요.
  • 스크린샷에서 읽은 글자는 저장하지 않아요. 종류(예: ‘영수증’)와, 쓸모가 지났는지 판단하기 위한 날짜(있을 때)만 남겨요.
  • 사진은 복사·업로드·공유되지 않아요. 사용자가 확인하지 않은 사진은 바꾸거나 지우지 않아요. 삭제한 사진은 ‘최근 삭제된 항목’에 약 30일간 남아요.

3. 말로 사진 찾기와 AI 모델

  • 무료: ‘스크린샷’, ‘작년 음식’ 같은 장면·종류·날짜 낱말 검색은 기기 안에서 이미 분석한 정보만 써요. 인터넷이 필요 없고, 무료 사용자는 AI 모델을 내려받지 않아요.
  • Pro: 설정 > AI 모델에서 사용자가 직접 시작하면 문장으로 찾는 데 쓰는 AI 모델(Google EmbeddingGemma 2, 약 388MB)을 한 번 내려받아요. 모델은 데이터 파일이며, 앱은 파일을 받기만 해요. 사진, 검색어, 기기 식별자는 보내지 않아요.
  • 모델 파일은 GitHub(GitHub Releases)에서 제공돼요. 다른 웹 파일을 받을 때처럼 IP 주소 같은 접속 정보가 GitHub의 접근 기록에 남을 수 있어요. 회사는 이 기록을 받거나 쓰지 않으며, GitHub의 개인정보 처리방침이 적용돼요.
  • 내려받은 뒤에는 기기 안에서만 동작해요. 앱은 사진의 축소 이미지를 모델에 넣어 만든 숫자 목록(검색 색인)을 기기에 저장하고, 검색어도 기기 안에서 숫자 목록으로 바꿔 비교해요. 검색 색인에는 사진 파일이나 이미지가 들어 있지 않아요.
  • 설정 > AI 모델에서 모델과 검색 색인을 언제든 지울 수 있어요. 둘 다 기기 백업에서 제외되고, 앱을 삭제하면 함께 사라져요.
  • 검색 결과는 참고용이에요. 결과에서 바로 사진을 지우지 않고, 사용자가 ‘정리 후보’에 담은 뒤 후보 보관함에서 확인해야 해요.

4. 기기에 저장되는 정보

앱은 분석 결과(이미지 특징, 선명도 점수, 장면·스크린샷 종류), 유지/후보 선택, 설정, 정리 누적 통계를 기기 안 앱 저장소에 보관해요. Pro에서 모델을 내려받았다면 모델 파일과 검색 색인도 기기에 있어요. 사진 파일이나 축소 이미지는 들어 있지 않아요. 앱 설정 > 분석 데이터 초기화로 분석 데이터를 지울 수 있고, 앱을 삭제하면 모두 사라져요.

5. Apple Watch

함께 쓰는 Watch 앱은 iPhone이 보낸 숫자(후보 수, 예상 용량, 마지막 분석 시각)만 보여 줘요. 사진이나 사진 식별자는 전송되지 않아요.

6. 결제

Framesift Pro(연간 구독 또는 평생 구매)는 Apple이 처리해요. 결제 정보는 회사가 보거나 저장하지 않아요. 구독은 설정 > Apple 계정 > 구독에서 관리·해지하고, 환불은 reportaproblem.apple.com에서 요청해요.

7. 아동

앱은 아동을 대상으로 하지 않으며 만 13세 미만 아동의 정보를 알면서 수집하지 않아요.
