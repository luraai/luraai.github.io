เริ่มต้นใช้งาน

ลองใช้โดยไม่มีเซิร์ฟเวอร์ได้ไหม

ที่แผงปฏิบัติการ แตะ “ลองโดยไม่ต้องมีเซิร์ฟเวอร์” แอปจะเพิ่มเซิร์ฟเวอร์เดโมและเซิร์ฟเวอร์จำลองที่ทำงานภายในแอป จึงไม่ต้องใช้เครือข่าย และคุณดูได้อย่างปลอดภัยว่าตัวป้องกันคำสั่งเสี่ยงจัดการกับ rm -rf อย่างไร

เพิ่มเซิร์ฟเวอร์จริงอย่างไร

ไปที่ โฮสต์ › + แล้วกรอกที่อยู่ พอร์ต ชื่อผู้ใช้ และวิธีเข้าสู่ระบบ (รหัสผ่านหรือคีย์) เมื่อเชื่อมต่อครั้งแรก แอปจะแสดงฟิงเกอร์พรินต์ของโฮสต์คีย์ ให้เทียบกับของเซิร์ฟเวอร์ก่อนจะเชื่อถือ

สร้างคีย์ SSH อย่างไร

ในหน้าคีย์ คุณสร้างคีย์ ed25519 และ ECDSA หรือนำเข้าคีย์ OpenSSH และ PEM ได้ (Pro) คีย์ Secure Enclave ได้รับการปกป้องด้วย Face ID และไม่ออกจากอุปกรณ์ ให้เพิ่มคีย์สาธารณะลงใน ~/.ssh/authorized_keys บนเซิร์ฟเวอร์

การสมัครสมาชิกและการซื้อ

อะไรใช้ฟรี และอะไรอยู่ใน Pro

ฟรี: SSH, SFTP และตัวป้องกันคำสั่งเสี่ยง (โฮสต์ 2 รายการ เชื่อมต่อใหม่ได้วันละ 3 ครั้ง แบ่งหน้าจอ 2 แผง) Pro: โฮสต์และการเชื่อมต่อไม่จำกัด AI บนอุปกรณ์ แบ่งหน้าจอ 4 แผง tmux เซิร์ฟเวอร์ Linux จำลอง โฟลเดอร์ SFTP การสร้างคีย์ การอนุมัติของเอเจนต์ และธีม Pro มีทั้งแบบสมัครสมาชิกรายเดือนหรือรายปี หรือซื้อครั้งเดียวแบบตลอดชีพ ราคาแตกต่างกันตามภูมิภาค

ยกเลิกหรือขอคืนเงินอย่างไร

ยกเลิกได้ที่ การตั้งค่า › [ชื่อของคุณ] › การสมัครสมาชิก คุณจะยังใช้ Pro ได้จนสิ้นสุดรอบที่ชำระแล้ว การคืนเงินดำเนินการโดย Apple: reportaproblem.apple.com

กู้คืนการซื้อบนอุปกรณ์เครื่องใหม่อย่างไร

แตะ “กู้คืนการซื้อ” ในหน้า Pro (การตั้งค่า › Hushterm Pro) โดยลงชื่อเข้าใช้ด้วยบัญชี Apple เดียวกัน

ปัญหาการเชื่อมต่อ

ขึ้นข้อความ “Permission denied”

ตรวจสอบชื่อผู้ใช้และรหัสผ่านหรือคีย์ รวมถึงว่าเซิร์ฟเวอร์อนุญาตวิธีนั้นหรือไม่ (PasswordAuthentication, PubkeyAuthentication) การวินิจฉัยการเชื่อมต่อของแอปจะชี้สาเหตุที่น่าจะเป็น

การเชื่อมต่อถูกบล็อกเพราะโฮสต์คีย์เปลี่ยน

นี่เป็นการออกแบบไว้โดยตั้งใจ เซิร์ฟเวอร์อาจถูกติดตั้งใหม่ หรือมีผู้ดักการเชื่อมต่ออยู่ หากคุณเปลี่ยนเซิร์ฟเวอร์เอง ให้ตรวจสอบฟิงเกอร์พรินต์ใหม่ แตะ “ลืมโฮสต์คีย์ที่บันทึกไว้” ในการวินิจฉัยการเชื่อมต่อ แล้วเชื่อมต่ออีกครั้ง

การเชื่อมต่อหมดเวลาหรือหลุดบ่อย

ตรวจสอบที่อยู่ พอร์ต และไฟร์วอลล์ เซิร์ฟเวอร์ในเครือข่ายของคุณเองต้องได้รับสิทธิ์เครือข่ายภายใน (การตั้งค่า › Hushterm) หากเปิด tmux แบบเชื่อมต่อทุกครั้งไว้สำหรับโฮสต์ เซสชันของคุณจะทำงานต่อหลังการเชื่อมต่อหลุด (Pro)

การเชื่อมต่อหลุดเมื่อแอปอยู่เบื้องหลัง

iOS จำกัดระยะเวลาที่แอปจะคงการเชื่อมต่อไว้ได้ขณะอยู่เบื้องหลัง tmux ช่วยให้คุณทำต่อจากจุดที่ค้างไว้ได้

AI และเอเจนต์

ฟีเจอร์ AI หายไปหรือไม่ทำงาน

ต้องใช้อุปกรณ์ที่รองรับ Apple Intelligence และเปิดไว้ที่ การตั้งค่า › Apple Intelligence บนอุปกรณ์อื่น คำอธิบายแบบอิงตามกฎจะยังทำงานต่อไป โดยค่าเริ่มต้น AI ทำงานบนอุปกรณ์

แอปเรียกใช้คำสั่งที่ AI เขียนโดยอัตโนมัติไหม

ไม่ คำแนะนำจะเติมลงในช่องป้อนคำสั่งเท่านั้น และคุณเป็นผู้ตัดสินใจว่าจะเรียกใช้หรือไม่ คำสั่งอย่าง rm -rf, dd, mkfs, chmod -R 777 หรือการรีบูตบนโปรดักชันจะหยุดรอก่อนส่ง

อนุมัติคำขอของ Claude Code / Codex อย่างไร

เมื่อเอเจนต์ในเซสชัน SSH ของคุณขอสิทธิ์ Hushterm จะตรวจพบข้อความขอสิทธิ์ในเทอร์มินัลและแสดงปุ่มอนุมัติ / ปฏิเสธในแอป iOS ไม่คงการเชื่อมต่อ SSH ไว้นานขณะอยู่เบื้องหลัง จึงใช้งานได้ขณะที่แอปเปิดอยู่ เมื่อใช้ Pro อาจมีการแจ้งเตือนภายในเครื่องปรากฏในช่วงสั้น ๆ หลังจากที่คุณออกจากแอป หากไม่เห็นอะไรเลย ให้เปิดการแจ้งเตือนที่ การตั้งค่า › การแจ้งเตือน

AI: การทดลองใช้ ปลายทางของคำขอ และการอนุมัติ

ลองใช้ AI โดยไม่มีเซิร์ฟเวอร์หรือคีย์ API ได้ไหม

ได้ ที่แผงปฏิบัติการ แตะ “ลองโดยไม่ต้องมีเซิร์ฟเวอร์” แอปจะเพิ่มเซิร์ฟเวอร์เดโม 1 เครื่องและเซิร์ฟเวอร์ Linux จำลอง 3 เครื่องไว้ในแอป พร้อมโมเดลสาธิตแบบออฟไลน์ โมเดลสาธิตใช้ได้เฉพาะกับเซิร์ฟเวอร์จำลองเหล่านี้เท่านั้น

คำขอ AI ของฉันถูกส่งไปที่ไหน

โดยค่าเริ่มต้น คำขอจะประมวลผลบนอุปกรณ์ด้วยโมเดลบนอุปกรณ์ของ Apple Intelligence หากคุณเชื่อมต่อคีย์ API ของคุณเองที่ การตั้งค่า › เอเจนต์ในตัว คำขอจะส่งตรงจากอุปกรณ์ของคุณไปยังผู้ให้บริการที่คุณเลือก และจะส่งหลังจากคุณยินยอมแล้วเท่านั้น คำขอไม่ผ่านเซิร์ฟเวอร์ของเราเลย คีย์ API เก็บไว้ในพวงกุญแจของอุปกรณ์เท่านั้นและไม่ซิงค์ไปยัง iCloud ดูรายละเอียดได้ที่นโยบายความเป็นส่วนตัว

เอเจนต์จะเปลี่ยนแปลงเซิร์ฟเวอร์ของฉันเองไหม

ไม่ มีเพียงคำสั่งแบบอ่านอย่างเดียวที่ทำงานเองได้ ทุกคำสั่งหรือการเปลี่ยนแปลงไฟล์จะรอการอนุมัติจากคุณก่อน คำสั่งอันตรายจะถูกบล็อกบนโฮสต์ที่ติดแท็กโปรดักชัน และคุณหยุดเอเจนต์ได้ทุกเมื่อ

การสำรองข้อมูลและข้อมูลของคุณ

ย้ายโฮสต์ไปยังอุปกรณ์เครื่องอื่นอย่างไร

เปิดการสำรองข้อมูลที่ การตั้งค่า › iCloud แล้วโฮสต์จะกู้คืนบนอุปกรณ์ที่ลงชื่อเข้าใช้ด้วยบัญชี Apple เดียวกัน รหัสผ่านจะตามมาด้วยก็ต่อเมื่อเปิด “เก็บรหัสผ่านไว้ในพวงกุญแจ iCloud ด้วย” ไว้ ส่วนคีย์ส่วนตัวจะไม่ออกจากอุปกรณ์ ให้นำเข้าอีกครั้งบนเครื่องใหม่

ข้อมูลของฉันอยู่ที่ไหน

อยู่บนอุปกรณ์ของคุณและใน iCloud ของคุณเองเท่านั้น ดูรายละเอียดในนโยบายความเป็นส่วนตัว
