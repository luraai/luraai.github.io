使い始めるには

サーバーなしで試せますか？

運用デッキで「サーバーなしで試す」をタップします。アプリ内でシミュレートされるデモサーバーと仮想サーバーが追加されるので、ネットワークは不要で、rm -rf に対して危険コマンド警告がどう働くかを安全に確認できます。

実際のサーバーはどう追加しますか？

ホスト › + に進み、アドレス、ポート、ユーザー名、ログイン方法（パスワードまたは鍵）を入力します。初回接続時にホストキーのフィンガープリントが表示されるので、信頼する前にサーバー側の値と照合してください。

SSH鍵はどう作りますか？

SSH鍵の画面で、ed25519とECDSAの鍵を生成したり、OpenSSHやPEMの鍵を読み込んだりできます（Pro）。Secure Enclave鍵はFace IDで保護され、デバイスの外には出ません。公開鍵をサーバーの ~/.ssh/authorized_keys に追加してください。

サブスクリプションと購入

無料とProの違いは何ですか？

無料：SSH、SFTP、危険コマンド警告（ホスト2件、1日の新規接続3回、2分割まで）。Pro：ホストと接続の無制限、オンデバイスAI、4分割、tmux、仮想Linuxサーバー、SFTPのフォルダ作成、鍵の作成、エージェントの承認、テーマ。Proは月額または年額のサブスクリプション、あるいは1回の購入で使える永久版です。価格は地域によって異なります。

キャンセルや返金はどうすればよいですか？

設定 › [ご自身の名前] › サブスクリプション からキャンセルできます。お支払い済みの期間が終わるまで、Proを利用できます。返金はAppleが対応します：reportaproblem.apple.com

新しいデバイスで購入を復元するには？

同じApple アカウントでサインインした状態で、Proの画面（設定 › Hushterm Pro）にある「購入を復元」をタップします。

接続のトラブル

「Permission denied」と表示されます。

ユーザー名、パスワードまたは鍵を確認し、サーバーがその方式（PasswordAuthentication、PubkeyAuthentication）を許可しているか確認してください。アプリの接続診断が、考えられる原因を示します。

ホストキーが変わったため、接続がブロックされます。

これは意図した動作です。サーバーが再インストールされたか、誰かが通信を傍受している可能性があります。ご自身でサーバーを変更した場合は、新しいフィンガープリントを確認し、接続診断で「保存済みのホストキーを削除」をタップして、もう一度接続してください。

接続がタイムアウトする、または頻繁に切れます。

アドレス、ポート、ファイアウォールを確認してください。同じネットワーク内のサーバーには、ローカルネットワークの権限が必要です（設定 › Hushterm）。ホストで「常にtmuxで接続」をオンにしておくと、切断後もセッションが継続します（Pro）。

バックグラウンドで接続が切れます。

iOSは、アプリがバックグラウンドにある間に接続を維持できる時間を制限しています。tmuxを使うと、中断したところから再開できます。

AIとエージェント

AI機能が表示されない、または動作しません。

Apple Intelligenceに対応したデバイスで、設定 › Apple IntelligenceとSiriからオンにする必要があります。それ以外のデバイスでも、ルールベースの説明は引き続き動作します。AIは初期設定ではデバイス内で動作します。

AIが作ったコマンドは自動で実行されますか？

いいえ。提案は入力欄に入るだけで、実行するかどうかはご自身で決めます。rm -rf、dd、mkfs、chmod -R 777 や本番サーバーの再起動などのコマンドは、送信前に一時停止します。

Claude Code / Codexのリクエストはどう承認しますか？

SSHセッション内のエージェントが許可を求めると、Hushtermがターミナル上でそのプロンプトを検出し、アプリ内に「承認」/「拒否」ボタンを表示します。iOSはバックグラウンドでSSH接続を長く維持しないため、この機能はアプリを開いている間に動作します。Proでは、アプリを離れてからしばらくの間、ローカル通知が表示されることがあります。何も表示されない場合は、設定 › 通知 で通知をオンにしてください。

AIの体験・送信先・承認

サーバーやAPIキーがなくてもAIを試せますか？

はい。運用デッキで「サーバーなしで試す」をタップすると、アプリ内にデモサーバーと3台の仮想Linuxサーバー、オフラインのデモモデルが追加されます。デモモデルはこれらの仮想サーバーでのみ動作します。

AIへのリクエストはどこに送られますか？

初期設定では、デバイス内のApple Intelligenceのオンデバイスモデルで処理されます。設定 › 内蔵エージェントでご自身のAPIキーを接続した場合に限り、お客様が同意した後で、リクエストがデバイスから選んだ提供元へ直接送られます。当社のサーバーを経由することはありません。APIキーはデバイスのキーチェーンにのみ保存され、iCloudには同期されません。詳しくはプライバシーポリシーをご覧ください。

エージェントが勝手にサーバーを変更しますか？

いいえ。自動で実行されるのは読み取り専用のコマンドだけで、コマンドの実行やファイルの変更は毎回お客様の承認を待ちます。本番タグの付いたホストでは危険なコマンドがブロックされ、いつでも停止できます。

バックアップとデータ

ホストを別のデバイスに移すには？

設定 › iCloudでバックアップをオンにすると、同じApple アカウントでサインインしたデバイスで復元されます。パスワードは「パスワードもiCloudキーチェーンに保存」がオンの場合のみ引き継がれます。秘密鍵はデバイスの外に出ないため、新しいデバイスで読み込み直してください。

データはどこにありますか？

お使いのデバイスと、ご自身のiCloudにのみあります。詳しくはプライバシーポリシーをご覧ください。
