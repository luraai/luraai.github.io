시작하기

서버가 없는데 써 볼 수 있나요?

호스트 탭 › "서버 없이 체험하기"를 누르면 앱 안에서 시뮬레이션되는 서버가 열립니다. 네트워크가 필요 없고, rm -rf 같은 위험한 명령도 안전하게 연습할 수 있어요.

실제 서버는 어떻게 추가하나요?

호스트 › + 에서 주소, 포트, 사용자 이름과 인증 방법(비밀번호 또는 키)을 입력하세요. 첫 접속 때 호스트 키 지문을 확인하는 창이 나옵니다. 서버의 지문과 같은지 확인한 뒤 신뢰하세요.

SSH 키는 어떻게 만드나요?

키 화면에서 ed25519·ECDSA 키를 만들거나 OpenSSH·PEM 키를 가져올 수 있어요(Pro). Secure Enclave 키는 Face ID로 보호되며 기기 밖으로 나가지 않습니다. 공개 키를 서버의 ~/.ssh/authorized_keys에 추가하세요.

구독과 구입

무료와 Pro는 무엇이 다른가요?

무료: SSH, SFTP, 위험 명령 경고(호스트 2개, 하루 새 연결 3회, 2분할). Pro: 호스트·연결 무제한, 온디바이스 AI, 4분할, tmux, 가상 리눅스 서버, SFTP 폴더, 키 생성, 에이전트 승인, 테마. 월간·연간 구독 또는 평생 이용권이며 가격은 지역에 따라 다릅니다.

구독을 해지하거나 환불받으려면?

구독은 설정 › [사용자 이름] › 구독에서 해지할 수 있고, 해지해도 결제 기간이 끝날 때까지 Pro를 쓸 수 있어요. 환불은 Apple이 처리합니다: reportaproblem.apple.com

다른 기기나 재설치 후 구입을 복원하려면?

Pro 화면(설정 › Hushterm Pro)의 "구입 복원"을 누르세요. 같은 Apple 계정이어야 합니다.

접속 문제

"Permission denied"가 나옵니다.

사용자 이름과 비밀번호 또는 키가 맞는지, 서버가 그 인증 방식을 허용하는지(PasswordAuthentication, PubkeyAuthentication) 확인하세요. 앱의 접속 진단이 원인을 알려 줍니다.

"호스트 키가 바뀌었다"며 접속이 막힙니다.

서버를 다시 설치했거나 중간자 공격일 수 있어서 의도적으로 차단합니다. 서버를 직접 바꾼 것이 맞다면 새 지문을 확인한 뒤 접속 진단에서 "저장된 호스트 키 지우기"를 누르고 다시 접속하세요.

접속이 시간 초과되거나 자꾸 끊깁니다.

주소·포트와 방화벽을 확인하세요. 같은 네트워크의 서버는 로컬 네트워크 권한(설정 › Hushterm)이 필요합니다. 호스트별로 tmux 자동 연결을 켜 두면 끊겨도 세션이 이어집니다(Pro).

백그라운드에서 연결이 끊겨요.

iOS는 앱이 백그라운드에 있을 때 연결을 오래 유지하지 못합니다. 남은 시간은 Live Activity로 보이며, tmux를 쓰면 돌아왔을 때 이어서 작업할 수 있어요.

AI와 에이전트

AI 기능이 보이지 않거나 동작하지 않아요.

AI 기능은 Apple Intelligence를 지원하는 기기에서 설정 › Apple Intelligence가 켜져 있어야 동작합니다. 그 외 기기에서는 규칙 기반 설명이 계속 동작합니다. 모든 AI는 기기 안에서 실행됩니다.

AI가 만든 명령이 자동으로 실행되나요?

아니요. 명령은 입력 줄에만 채워지고 직접 실행해야 합니다. rm -rf, dd, mkfs, chmod -R 777, 재부팅 같은 위험한 명령은 운영 호스트에서 전송 전에 한 번 멈춥니다.

Claude Code / Codex 승인 알림은 어떻게 받나요?

SSH 세션에서 에이전트가 승인을 요청하면 알림, Live Activity, Apple Watch로 알려 드립니다(Pro). 위험도가 낮은 요청만 잠금 화면에서 승인할 수 있고, 나머지는 앱에서 확인합니다. 알림 권한이 꺼져 있으면 설정 › 알림에서 켜 주세요.

백업과 데이터

호스트를 다른 기기로 옮기려면?

설정 › iCloud에서 백업을 켜면 같은 Apple 계정의 기기에서 복원됩니다. 비밀번호는 "iCloud 키체인에도 비밀번호 보관"을 켠 경우에만 함께 옮겨지고, 개인 키는 기기를 떠나지 않으므로 새 기기에서 다시 가져와야 합니다.

내 데이터는 어디에 있나요?

기기와 사용자의 iCloud에만 있습니다. 자세한 내용은 개인정보 처리방침을 참고하세요.
