入门

没有服务器也能试用吗？

打开“主机”标签页，点按“无需服务器，先试试”。它会打开一台在 App 内模拟的服务器，无需联网，您可以放心地看看危险命令警告会如何处理 rm -rf。

如何添加真实服务器？

前往“主机”› +，输入地址、端口、用户名和登录方式（密码或密钥）。首次连接时，App 会显示主机密钥指纹；信任之前，请先与服务器上的指纹进行比对。

如何创建 SSH 密钥？

在“密钥”界面，可以生成 ed25519 和 ECDSA 密钥，或导入 OpenSSH 和 PEM 密钥（Pro）。Secure Enclave 密钥受 Face ID 保护，永远不会离开设备。请把公钥添加到服务器上的 ~/.ssh/authorized_keys 中。

订阅与购买

免费版和 Pro 分别有什么？

免费：SSH、SFTP 和危险命令警告（2 个主机，每天 3 次新连接，2 窗格分屏）。Pro：不限主机和连接数、设备端 AI、4 窗格分屏、tmux、虚拟 Linux 服务器、SFTP 文件夹、密钥创建、智能体批准和主题。Pro 提供月度或年度订阅，也可一次性购买永久使用；价格因地区而异。

如何取消订阅或申请退款？

在“设置”› [您的姓名] › 订阅中取消。付费周期结束前仍可继续使用 Pro。退款由 Apple 处理：reportaproblem.apple.com

如何在新设备上恢复购买？

在 Pro 页面（设置 › Hushterm Pro）点按“恢复购买”，并使用同一个 Apple 账户登录。

连接问题

出现“Permission denied”。

请检查用户名、密码或密钥，并确认服务器允许该方式（PasswordAuthentication、PubkeyAuthentication）。App 的连接诊断会指出可能的原因。

因主机密钥已变更，连接被阻止。

这是有意为之：服务器可能已被重装，也可能有人在拦截连接。如果是您自己更改了服务器，请核实新的指纹，在连接诊断中点按“忘记已存储的主机密钥”，然后重新连接。

连接超时或不断断开。

请检查地址、端口和防火墙。您自己网络中的服务器需要“本地网络”权限（设置 › Hushterm）。如果为某个主机开启了“始终使用 tmux 连接”，断线后会话仍会继续（Pro）。

在后台时连接断开。

iOS 会限制 App 在后台保持连接的时间。借助 tmux，可以从中断的地方继续。

AI 与智能体

AI 功能缺失或无法使用。

需要支持 Apple 智能的设备，并在“设置”›“Apple 智能”中开启。在其他设备上，基于规则的说明仍可使用。所有 AI 都在设备上运行。

App 会自动运行 AI 写出的命令吗？

不会。建议只会填入输入行，是否运行由您决定。rm -rf、dd、mkfs、chmod -R 777 等命令，或在生产环境重启，都会在发送前暂停。

如何批准 Claude Code / Codex 的请求？

当您 SSH 会话中的智能体请求权限时，Hushterm 会在终端中检测到该提示，并在 App 中显示“批准”和“拒绝”按钮。iOS 不会让 SSH 连接在后台长时间保持，因此这在 App 打开期间可用；使用 Pro 时，离开 App 后的短时间内可能会出现本地通知。如果什么都没看到，请在“设置”›“通知”中开启通知。

备份与数据

如何把主机迁移到另一台设备？

在“设置”› iCloud 中开启备份，登录同一个 Apple 账户的设备上就会恢复。只有开启“同时将密码保存在 iCloud 钥匙串中”时，密码才会一起迁移；私钥绝不会离开设备，因此请在新设备上重新导入。

我的数据在哪里？

只在您的设备和您自己的 iCloud 中。详情请参阅隐私政策。
