Getting started

Can I try it without a server?

Open the Hosts tab and tap “Try it without a server”. It opens a server simulated inside the app, so no network is needed and you can safely see what the risky-command guard does with rm -rf.

How do I add a real server?

Go to Hosts › + and enter the address, port, username and how you sign in (password or key). On the first connection the app shows the host-key fingerprint; compare it with the server’s before you trust it.

How do I create an SSH key?

On the Keys screen you can generate ed25519 and ECDSA keys or import OpenSSH and PEM keys (Pro). Secure Enclave keys are protected by Face ID and never leave the device. Add the public key to ~/.ssh/authorized_keys on the server.

Subscriptions and purchases

What is free, and what is Pro?

Free: SSH, SFTP and the risky-command guard (2 hosts, 3 new connections a day, 2-pane split). Pro: unlimited hosts and connections, on-device AI, 4-pane split, tmux, virtual Linux servers, SFTP folders, key creation, agent approvals and themes. Pro is a monthly or yearly subscription, or a one-time lifetime purchase; prices vary by region.

How do I cancel or get a refund?

Cancel in Settings › [your name] › Subscriptions. You keep Pro until the paid period ends. Refunds are handled by Apple: reportaproblem.apple.com

How do I restore purchases on a new device?

Tap “Restore Purchases” on the Pro screen (Settings › Hushterm Pro), signed in with the same Apple Account.

Connection problems

I get “Permission denied”.

Check the username and password or key, and that the server allows that method (PasswordAuthentication, PubkeyAuthentication). The app’s connection diagnosis points to the likely cause.

The connection is blocked because the host key changed.

This is deliberate: the server may have been reinstalled, or someone may be intercepting the connection. If you changed the server yourself, verify the new fingerprint, tap “Forget saved host key” in the connection diagnosis and connect again.

Connections time out or keep dropping.

Check the address, port and firewall. Servers on your own network need the Local Network permission (Settings › Hushterm). With always-attach tmux on for a host, your session carries on after a drop (Pro).

The connection drops in the background.

iOS limits how long an app can keep a connection while in the background. A Live Activity shows the remaining time, and tmux lets you pick up where you left off.

AI and agents

AI features are missing or not working.

They need a device that supports Apple Intelligence, with it turned on in Settings › Apple Intelligence. On other devices the rule-based explanations keep working. All AI runs on the device.

Does the app run AI-written commands automatically?

No. A suggestion only fills the input line and you decide whether to run it. Commands such as rm -rf, dd, mkfs, chmod -R 777 or a reboot on production pause before sending.

How do I get Claude Code / Codex approval alerts?

When an agent in your SSH session asks for approval, Hushterm notifies you by notification, Live Activity and Apple Watch (Pro). Only low-risk requests can be approved from the lock screen; the rest open the app. If you see nothing, turn notifications on in Settings › Notifications.

Backup and data

How do I move my hosts to another device?

Turn on backup in Settings › iCloud and they restore on devices signed in to the same Apple Account. Passwords come along only if “Also keep passwords in iCloud Keychain” is on; private keys never leave a device, so import them again on the new one.

Where is my data?

Only on your device and in your own iCloud. See the Privacy Policy for details.
