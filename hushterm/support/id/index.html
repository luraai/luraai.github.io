Memulai

Bisakah saya mencobanya tanpa server?

Buka tab Host dan ketuk “Coba tanpa server”. Ini membuka server simulasi di dalam aplikasi, sehingga tidak perlu jaringan dan Anda bisa melihat dengan aman apa yang dilakukan peringatan perintah berisiko terhadap rm -rf.

Bagaimana cara menambahkan server sungguhan?

Buka Host › + lalu masukkan alamat, port, nama pengguna, dan cara masuk (kata sandi atau kunci). Pada koneksi pertama, aplikasi menampilkan fingerprint kunci host; bandingkan dengan fingerprint dari server sebelum Anda mempercayainya.

Bagaimana cara membuat kunci SSH?

Di layar Kunci, Anda dapat membuat kunci ed25519 dan ECDSA atau mengimpor kunci OpenSSH dan PEM (Pro). Kunci Secure Enclave dilindungi Face ID dan tidak pernah meninggalkan perangkat. Tambahkan kunci publik ke ~/.ssh/authorized_keys di server.

Langganan dan pembelian

Apa yang gratis, dan apa yang termasuk Pro?

Gratis: SSH, SFTP, dan peringatan perintah berisiko (2 host, 3 koneksi baru per hari, layar terbagi 2 panel). Pro: host dan koneksi tanpa batas, AI di perangkat, layar terbagi 4 panel, tmux, server Linux virtual, folder SFTP, pembuatan kunci, persetujuan agen, dan tema. Pro tersedia sebagai langganan bulanan atau tahunan, atau pembelian seumur hidup sekali bayar; harga berbeda di tiap wilayah.

Bagaimana cara membatalkan atau meminta pengembalian dana?

Batalkan di Pengaturan › [nama Anda] › Langganan. Pro tetap aktif sampai periode yang sudah dibayar berakhir. Pengembalian dana ditangani oleh Apple: reportaproblem.apple.com

Bagaimana cara memulihkan pembelian di perangkat baru?

Ketuk “Pulihkan pembelian” di layar Pro (Pengaturan › Hushterm Pro), dengan masuk menggunakan Akun Apple yang sama.

Masalah koneksi

Saya mendapat “Permission denied”.

Periksa nama pengguna dan kata sandi atau kunci, serta pastikan server mengizinkan metode tersebut (PasswordAuthentication, PubkeyAuthentication). Diagnosis koneksi di aplikasi menunjukkan kemungkinan penyebabnya.

Koneksi diblokir karena kunci host berubah.

Ini disengaja: server mungkin telah diinstal ulang, atau seseorang mungkin sedang menyadap koneksi. Jika Anda sendiri yang mengubah server, verifikasi fingerprint baru, ketuk “Lupakan kunci host tersimpan” di diagnosis koneksi, lalu hubungkan lagi.

Koneksi habis waktu atau terus terputus.

Periksa alamat, port, dan firewall. Server di jaringan Anda sendiri memerlukan izin Jaringan Lokal (Pengaturan › Hushterm). Dengan opsi “Selalu hubungkan dengan tmux” aktif untuk sebuah host, sesi Anda tetap berlanjut setelah koneksi terputus (Pro).

Koneksi terputus di latar belakang.

iOS membatasi berapa lama aplikasi dapat mempertahankan koneksi saat berada di latar belakang. tmux memungkinkan Anda melanjutkan dari titik terakhir.

AI dan agen

Fitur AI tidak ada atau tidak berfungsi.

Fitur ini memerlukan perangkat yang mendukung Apple Intelligence, dan harus diaktifkan di Pengaturan › Apple Intelligence. Di perangkat lain, penjelasan berbasis aturan tetap berfungsi. Semua AI berjalan di perangkat.

Apakah aplikasi menjalankan perintah buatan AI secara otomatis?

Tidak. Saran hanya mengisi baris input dan Anda sendiri yang memutuskan apakah akan menjalankannya. Perintah seperti rm -rf, dd, mkfs, chmod -R 777, atau reboot di produksi dijeda sebelum dikirim.

Bagaimana cara menyetujui permintaan Claude Code / Codex?

Ketika agen di sesi SSH Anda meminta izin, Hushterm mendeteksi permintaan itu di terminal dan menampilkan tombol Setujui / Tolak di aplikasi. iOS tidak mempertahankan koneksi SSH dalam waktu lama di latar belakang, jadi ini berfungsi saat aplikasi terbuka; dengan Pro, notifikasi lokal dapat muncul untuk waktu singkat setelah Anda meninggalkan aplikasi. Jika tidak ada yang muncul, aktifkan notifikasi di Pengaturan › Notifikasi.

Cadangan dan data

Bagaimana cara memindahkan host ke perangkat lain?

Aktifkan pencadangan di Pengaturan › iCloud, maka host akan dipulihkan di perangkat yang masuk dengan Akun Apple yang sama. Kata sandi ikut hanya jika “Simpan juga kata sandi di Rantai Kunci iCloud” aktif; kunci privat tidak pernah meninggalkan perangkat, jadi impor ulang di perangkat baru.

Di mana data saya?

Hanya di perangkat Anda dan di iCloud Anda sendiri. Lihat Kebijakan Privasi untuk detailnya.
