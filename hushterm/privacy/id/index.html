Kebijakan Privasi

Berlaku sejak: 31 Oktober 2026 · English · 한국어

Hushterm tidak memiliki akun dan tidak mengirim apa pun ke server LuraAI. Perintah dan output terminal Anda hanya berpindah antara perangkat Anda dan server yang Anda pilih, dan secara default AI berjalan di perangkat. Hanya jika Anda menghubungkan penyedia AI Anda sendiri, data dikirim dari perangkat Anda langsung ke penyedia tersebut. Tidak ada analitik, iklan, atau SDK pelacakan.

1. Data yang kami kumpulkan

LuraAI (“kami”) tidak mengumpulkan informasi pribadi apa pun melalui Hushterm (“aplikasi”).

  • Tidak ada pendaftaran dan tidak ada login.
  • Kami tidak pernah meminta atau mengumpulkan nama, email, nomor telepon, atau lokasi.
  • Kami tidak memakai framework analitik, pelacakan, atau iklan, dan tidak menyertakan SDK pihak ketiga.
  • Aplikasi tidak berisi kode jaringan yang mengirim data kepada kami.

2. Yang disimpan di perangkat Anda

Hal-hal berikut tetap di perangkat Anda dan diperlukan agar aplikasi berfungsi:

  • Detail host (nama, alamat, port, nama pengguna, tag), folder, port forwarding, snippet, dan perintah terbaru
  • Kata sandi SSH dan kunci privat, disimpan di Rantai Kunci iOS. Kunci Secure Enclave tidak dapat meninggalkan perangkat, dan kunci privat tidak pernah meninggalkannya.
  • Fingerprint kunci host dari server yang pernah Anda hubungi (dikonfirmasi saat pertama kali dipakai)
  • Laporan pemeriksaan server (beberapa yang terakhir per host), riwayat permintaan agen AI dan keputusan Anda, pemeriksaan server buatan Anda sendiri, serta progres kursus latihan
  • Pengaturan aplikasi (tema, bilah tombol, scrollback, kunci aplikasi, dan sebagainya) serta hak Pro Anda
  • Playbook, log operasi (riwayat dek operasi), hasil pertanyaan armada, dan hasil lensa log
  • Pengaturan penyedia AI (penyedia, alamat, model, dan persetujuan Anda untuk setiap penyedia dan alamat). Kunci API untuk penyedia AI Anda hanya disimpan di Rantai Kunci perangkat dan tidak pernah disinkronkan ke iCloud.

3. Koneksi server dan konten terminal

Koneksi SSH dan SFTP berjalan langsung dari perangkat Anda ke server yang Anda tentukan; tidak ada relay LuraAI yang terlibat. Kami tidak dapat melihat output terminal atau file yang Anda transfer. Apa yang terjadi di server diatur oleh operator server tersebut.

Pemeriksaan server. Pemeriksaan server hanya menjalankan perintah read-only (dari daftar izin tetap, atau perintah yang Anda tulis dan lolos daftar izin yang sama) pada server yang Anda pilih, melalui koneksi SSH Anda sendiri. Hasilnya dinilai di perangkat dan disimpan di perangkat; tidak ada yang dikirim kepada kami atau pihak lain mana pun, kecuali ringkasan yang Anda kirim ke penyedia AI Anda sendiri seperti dijelaskan di bagian 4. Kursus latihan Linux berjalan di server simulasi di dalam aplikasi dan tidak memakai jaringan.

4. Fitur AI dan input suara

Secara default, saran perintah, analisis error, ringkasan output, diagnosis koneksi, penjelasan lensa log, jawaban pertanyaan armada, dan penjelasan playbook dibuat di perangkat oleh model on-device Apple Intelligence; jika model itu tidak tersedia, aplikasi menampilkan kalimat yang ditulis oleh aturan di perangkat. Model demo yang dipakai di server virtual dalam aplikasi berjalan dengan skenario tetap yang ada di dalam aplikasi dan tidak memakai jaringan. Penilaian perintah berbahaya dan hasil pemeriksaan ditentukan oleh mesin aturan di perangkat, bukan oleh model. Input suara hanya memakai pengenalan suara di perangkat.

Penyedia AI yang Anda hubungkan sendiri (opsional, Pro). Hanya jika Anda menghubungkan Anthropic (Claude), layanan yang kompatibel dengan OpenAI, atau model di server Anda sendiri dengan kunci API Anda sendiri di Pengaturan › Agen bawaan, data berikut dikirim langsung dari perangkat Anda ke penyedia tersebut saat Anda memakai agen bawaan atau investigasi AI, atau saat aplikasi menulis penjelasan untuk pertanyaan armada, lensa log, atau playbook: tujuan atau pertanyaan yang Anda tulis; nama server, sistem operasi, dan apakah server itu produksi; output perintah baca-saja yang dijalankan aplikasi dan perintah yang Anda setujui; serta ringkasan hasil pemeriksaan dan log. Sebelum mengirim, aplikasi otomatis menyamarkan nilai rahasia seperti kunci privat, token, dan kata sandi, tetapi tidak dapat mengenali semua rahasia. Pengiriman ini tidak melewati server kami, dan kami tidak dapat melihat isinya. Cara penyedia memproses data yang diterimanya diatur oleh ketentuan dan kebijakan privasi penyedia tersebut. Sebelum penggunaan pertama, aplikasi menampilkan penyedia, alamat, dan data yang akan dikirim lalu meminta persetujuan Anda (dicatat per penyedia dan alamat); Anda dapat mencabut persetujuan dan menghapus kunci di Pengaturan. Jika Anda menghubungkan server yang berjalan di jaringan yang sama atau di perangkat ini, data tidak keluar ke internet. Jika Anda tidak menghubungkan penyedia, tidak ada data yang dikirim ke layanan AI pihak ketiga.

5. Cadangan iCloud — penyimpanan Anda, bukan milik kami

Jika Anda mengaktifkan pencadangan iCloud, detail host, port forwarding, snippet, dan folder disimpan di akun Apple Anda sendiri melalui penyimpanan key-value iCloud milik Apple. Kami tidak dapat mengaksesnya. Kata sandi SSH tersinkron melalui Rantai Kunci iCloud hanya jika Anda mengaktifkan “Simpan juga kata sandi di Rantai Kunci iCloud” (nonaktif secara default); kunci privat tidak pernah disinkronkan. Anda dapat mematikannya kapan saja di Pengaturan › iCloud.

6. Persetujuan agen AI, widget, dan Apple Watch

Ketika agen coding AI seperti Claude Code atau Codex yang berjalan di dalam sesi SSH Anda sendiri meminta izin, Hushterm mendeteksi permintaan itu pada teks terminal di perangkat dan menampilkan tombol Setujui / Tolak di aplikasi. Hushterm sendiri tidak pernah menghubungi agen tersebut atau penyedianya. Dengan Pro, notifikasi lokal dapat muncul di perangkat untuk waktu singkat setelah Anda meninggalkan aplikasi. Notifikasi persetujuan dan Live Activity dibuat secara lokal di perangkat; tidak ada server push yang digunakan. Daftar host dan permintaan persetujuan Anda hanya berpindah antara iPhone dan Apple Watch dan tidak melewati server mana pun.

8. Papan klip

Pelindung tempel memperbaiki tanda kutip pintar dan tanda pisah serta bertanya sebelum tempelan multibaris dijalankan, tepat saat Anda menempel, di perangkat. Pelindung ini tidak menyimpan atau mengirimkan isi papan klip.

9. Pembelian dalam aplikasi

Langganan bulanan dan tahunan serta pembelian seumur hidup dijual melalui StoreKit milik Apple. Pembayaran dan validasi kuitansi ditangani sepenuhnya oleh Apple; kami tidak pernah menerima detail pembayaran atau informasi Akun Apple. Kelola atau batalkan langganan di pengaturan Akun Apple Anda.

10. Berbagi dan penjualan

Kami tidak mengumpulkan informasi pribadi dan tidak menjual atau membagikan data Anda. Satu-satunya pengecualian adalah data yang Anda pilih untuk dikirim ke penyedia AI Anda sendiri, seperti dijelaskan di bagian 4. Aplikasi tidak memakai cookie, pengidentifikasi iklan (IDFA), atau pelacakan lintas aplikasi.

11. Enkripsi

Aplikasi hanya memakai enkripsi SSH standar.

12. Anak-anak

Kami tidak mengumpulkan informasi pribadi dari siapa pun, termasuk anak-anak.

13. Menghapus data Anda

Menghapus aplikasi akan menghapus host, pengaturan, dan item Rantai Kunci dari perangkat. Data yang dicadangkan ke iCloud dapat dihapus di Pengaturan › [nama Anda] › iCloud › Kelola Penyimpanan.

14. Perubahan pada kebijakan ini

Jika kebijakan ini berubah, tanggal berlaku di atas ikut berubah, dan perubahan penting diumumkan di catatan pembaruan aplikasi.
