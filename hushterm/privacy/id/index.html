Kebijakan Privasi

Berlaku sejak: 17 Oktober 2026 · English · 한국어

Hushterm tidak memiliki akun dan tidak mengirim apa pun ke server LuraAI. Perintah dan output terminal Anda hanya berpindah antara perangkat Anda dan server yang Anda pilih, dan semua fitur AI berjalan di perangkat. Tidak ada analitik, iklan, atau SDK pelacakan.

1. Data yang kami kumpulkan

LuraAI (“kami”) tidak mengumpulkan informasi pribadi apa pun melalui Hushterm (“aplikasi”).

  • Tidak ada pendaftaran dan tidak ada login.
  • Kami tidak pernah meminta atau mengumpulkan nama, email, nomor telepon, atau lokasi.
  • Kami tidak memakai framework analitik, pelacakan, atau iklan, dan tidak menyertakan SDK pihak ketiga.
  • Aplikasi tidak berisi kode jaringan yang mengirim data kepada kami.

2. Yang disimpan di perangkat Anda

Hal-hal berikut tetap di perangkat Anda dan diperlukan agar aplikasi berfungsi:

  • Detail host (nama, alamat, port, nama pengguna, tag), folder, port forwarding, snippet, dan perintah terbaru
  • Kata sandi SSH dan kunci privat, disimpan di Rantai Kunci iOS. Kunci Secure Enclave tidak dapat meninggalkan perangkat, dan kunci privat tidak pernah meninggalkannya.
  • Fingerprint kunci host dari server yang pernah Anda hubungi (dikonfirmasi saat pertama kali dipakai)
  • Laporan pemeriksaan server (beberapa yang terakhir per host), riwayat permintaan agen AI dan keputusan Anda, pemeriksaan server buatan Anda sendiri, serta progres kursus latihan
  • Pengaturan aplikasi (tema, bilah tombol, scrollback, kunci aplikasi, dan sebagainya) serta hak Pro Anda

3. Koneksi server dan konten terminal

Koneksi SSH dan SFTP berjalan langsung dari perangkat Anda ke server yang Anda tentukan; tidak ada relay LuraAI yang terlibat. Kami tidak dapat melihat output terminal atau file yang Anda transfer. Apa yang terjadi di server diatur oleh operator server tersebut.

Pemeriksaan server. Pemeriksaan server hanya menjalankan perintah read-only (dari daftar izin tetap, atau perintah yang Anda tulis dan lolos daftar izin yang sama) pada server yang Anda pilih, melalui koneksi SSH Anda sendiri. Hasilnya dinilai di perangkat dan disimpan di perangkat; tidak ada yang dikirim kepada kami atau pihak lain mana pun. Kursus latihan Linux berjalan di server simulasi di dalam aplikasi dan tidak memakai jaringan.

4. Fitur AI dan input suara

Saran perintah, analisis error, ringkasan output panjang, dan diagnosis koneksi berjalan di perangkat dengan model di perangkat milik Apple Intelligence (Foundation Models) dan tidak memakai jaringan. Input suara hanya memakai pengenalan ucapan di perangkat; audio tidak pernah dikirim ke server. Peringatan perintah berisiko diputuskan oleh mesin aturan di perangkat, bukan oleh model.

Tanpa layanan AI pihak ketiga. Hushterm tidak menggunakan, memanggil, atau membagikan data dengan layanan AI pihak ketiga mana pun (bukan OpenAI, Anthropic, Google, atau sejenisnya), dan tidak memiliki server AI sendiri. Teks yang dibaca fitur-fitur ini — perintah yang Anda ketik, output terminal terbaru, dan pesan error dari perintah yang gagal — hanya diteruskan ke model di perangkat milik Apple pada iPhone atau iPad Anda, tetap berada di memori, tidak kami simpan, dan tidak pernah meninggalkan perangkat. Karena tidak ada data pribadi yang dikirim ke pihak ketiga mana pun untuk keperluan AI, tidak ada yang perlu disetujui atau dibagikan. Jika hal ini suatu saat berubah, aplikasi akan lebih dulu menampilkan data apa yang akan dikirim dan kepada siapa, serta meminta izin Anda sebelum mengirim apa pun.

5. Cadangan iCloud — penyimpanan Anda, bukan milik kami

Jika Anda mengaktifkan pencadangan iCloud, detail host, port forwarding, snippet, dan folder disimpan di akun Apple Anda sendiri melalui penyimpanan key-value iCloud milik Apple. Kami tidak dapat mengaksesnya. Kata sandi SSH tersinkron melalui Rantai Kunci iCloud hanya jika Anda mengaktifkan “Simpan juga kata sandi di Rantai Kunci iCloud” (nonaktif secara default); kunci privat tidak pernah disinkronkan. Anda dapat mematikannya kapan saja di Pengaturan › iCloud.

6. Persetujuan agen AI, widget, dan Apple Watch

Ketika agen coding AI seperti Claude Code atau Codex yang berjalan di dalam sesi SSH Anda sendiri meminta izin, Hushterm mendeteksi permintaan itu pada teks terminal di perangkat dan menampilkan tombol Setujui / Tolak di aplikasi. Hushterm sendiri tidak pernah menghubungi agen tersebut atau penyedianya. Dengan Pro, notifikasi lokal dapat muncul di perangkat untuk waktu singkat setelah Anda meninggalkan aplikasi. Tidak ada server push yang digunakan. Daftar host dan permintaan persetujuan Anda hanya berpindah antara iPhone dan Apple Watch dan tidak melewati server mana pun.

Menolak sebuah izin hanya menonaktifkan fitur yang membutuhkannya.

8. Papan klip

Pelindung tempel memperbaiki tanda kutip pintar dan tanda pisah serta bertanya sebelum tempelan multibaris dijalankan, tepat saat Anda menempel, di perangkat. Pelindung ini tidak menyimpan atau mengirimkan isi papan klip.

9. Pembelian dalam aplikasi

Langganan bulanan dan tahunan serta pembelian seumur hidup dijual melalui StoreKit milik Apple. Pembayaran dan validasi kuitansi ditangani sepenuhnya oleh Apple; kami tidak pernah menerima detail pembayaran atau informasi Akun Apple. Kelola atau batalkan langganan di pengaturan Akun Apple Anda.

10. Berbagi dan penjualan

Kami tidak mengumpulkan informasi pribadi, sehingga tidak ada yang dapat dibagikan atau dijual kepada siapa pun. Aplikasi tidak memakai cookie, pengidentifikasi iklan (IDFA), atau pelacakan lintas aplikasi.

11. Enkripsi

Aplikasi hanya memakai enkripsi SSH standar.

12. Anak-anak

Kami tidak mengumpulkan informasi pribadi dari siapa pun, termasuk anak-anak.

13. Menghapus data Anda

Menghapus aplikasi akan menghapus host, pengaturan, dan item Rantai Kunci dari perangkat. Data yang dicadangkan ke iCloud dapat dihapus di Pengaturan › [nama Anda] › iCloud › Kelola Penyimpanan.

14. Perubahan pada kebijakan ini

Jika kebijakan ini berubah, tanggal berlaku di atas ikut berubah, dan perubahan penting diumumkan di catatan pembaruan aplikasi.
