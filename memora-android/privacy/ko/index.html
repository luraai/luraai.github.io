Memora 개인정보 처리방침

시행일: 2026년 10월 16일

English 日本語 한국어 简体中文 繁體中文

Memora(Android)는 계정이 없고, 카드·학습 기록을 LuraAI 서버로 보내지 않습니다. 임베딩·AI 덱 생성·문서 분석은 모두 기기 안에서 실행됩니다. 분석·광고·추적 SDK는 없습니다.

1. 수집하는 정보

LuraAI(이하 "회사")는 Memora(이하 "앱")를 통해 개인정보를 수집하지 않습니다.

  • 회원가입과 로그인이 없습니다.
  • 이름, 이메일, 전화번호, 위치 정보를 요청하거나 수집하지 않습니다.
  • 분석, 광고, 추적용 프레임워크와 제3자 SDK를 포함하지 않으며, 광고 ID를 사용하지 않습니다.
  • 앱에는 사용자의 카드나 학습 기록을 회사에 보내는 코드가 없습니다.

2. 기기에 저장되는 정보

앱이 동작하는 데 필요한 다음 정보는 사용자의 기기 안에만 저장됩니다.

  • 덱, 카드, 복습 기록(복습한 시각과 평가), 군집·헷갈리는 쌍 같은 분석 결과
  • 카드의 뜻을 비교하기 위한 임베딩(수치 벡터). 기기에서 계산합니다.
  • 문서·사진으로 카드를 만들 때 읽어 낸 본문, 만든 퀴즈와 퀴즈 풀이 기록·오답 노트(기기에만 보관)
  • 앱 설정(테마, 글꼴, 읽어주기 음성, 복습 알림 시각 등)과 Pro 이용 여부
  • 홈 화면 위젯에 보여 줄 오늘 복습할 카드 수와 연속 학습일(위젯 표시용으로 기기 안에서만 사용)
  • 사용자가 파일 백업 기능으로 직접 고른 위치에 저장한 백업 파일. 이 파일은 사용자가 보관·관리하며 회사로 전송되지 않습니다.

3. 기기 백업(Android 자동 백업)

기기의 Android 자동 백업이 켜져 있으면, 앱 데이터가 사용자 본인의 Google 계정 백업에 저장되고 새 기기로 옮길 때 복원될 수 있습니다. 이 백업은 Android와 Google이 제공하는 기능이며, 사용자가 기기 설정에서 켜고 끌 수 있습니다. 회사는 이 백업 데이터에 접근할 수 없습니다. 앱의 파일 백업·복원 기능은 이와 별개로, 사용자가 고른 위치에 백업 파일을 직접 만들고 불러오는 기능입니다.

4. 네트워크를 사용하는 경우

앱은 사용자의 카드를 서버로 보내지 않습니다. 네트워크는 다음 경우에만 사용합니다.

  • 모델 파일 내려받기: 의미 분석용 임베딩 모델(약 165MB)과, 사용자가 고르는 AI 덱 만들기용 언어 모델(Gemma 4 약 2.6GB, Qwen3 약 1GB 또는 2.7GB)을 Hugging Face에서 내려받습니다. 내려받기 전에 용량과 데이터 사용 안내를 보여 주며, 사용자가 확인해야만 시작합니다(설정 > AI 모델). 파일을 받는 일반 요청이며 카드나 학습 내용은 전송되지 않습니다. 이 요청에는 Hugging Face의 개인정보 처리방침이 적용됩니다(예: IP 주소). 내려받은 모델은 설정에서 언제든 삭제할 수 있습니다.
  • 결제: 평생 이용 구매는 Google Play가 처리합니다. 회사는 결제 수단 정보를 받지 않습니다. 구매 여부 확인은 Google Play 결제 서비스를 통해 이루어집니다.

복습·퀴즈 같은 핵심 기능은 인터넷 연결 없이도 동작합니다. 전송 중인 데이터는 HTTPS로 암호화됩니다.

Wear OS 워치(선택): 워치 앱을 설치하면 오늘 복습할 카드·퀴즈와 평가 내용이 Google 의 Wearable Data Layer(Google Play 서비스)를 통해 폰과 페어링된 워치 사이에서만 오갑니다. 이 데이터를 Memora 의 서버로 보내지 않습니다.

앱은 큰 모델을 내려받기 전에 경고하기 위해 모바일 데이터 사용 여부(네트워크 상태 권한)도 확인합니다.

5. AI 기능

카드 중복·헷갈리는 쌍 찾기, 의미 검색, 문서에서 카드·퀴즈 만들기, AI로 덱 만들기는 모두 기기 안에서 내려받은 모델(EmbeddingGemma, Gemma 4, Qwen3)로 실행되며 입력한 주제와 문서는 기기 밖으로 나가지 않습니다. 모델이 없으면 글자 기반 분석으로 동작합니다. AI가 만든 카드는 틀릴 수 있으므로 저장하기 전에 직접 확인해 주세요. 의료·법률·세금·투자 같은 주제는 특히 공식 자료로 확인하시기 바랍니다.

6. 기기 권한

  • 인터넷: 모델 파일 내려받기와 결제 확인에만 사용합니다.
  • 알림: 복습 알림을 켠 경우에만 요청하며(선택), 알림은 기기에서 예약되고 서버를 거치지 않습니다.
  • 결제(com.android.vending.BILLING): Google Play 결제를 위해 사용합니다.
  • 카메라: 앱은 카메라 권한을 요청하지 않습니다. 교재 사진을 찍을 때는 기기의 카메라 앱을 호출하며, 사진은 기기 안에서 글자를 읽는 데만 사용하고 서버로 보내지 않습니다.
  • 사진·파일: 사용자가 시스템 선택 화면에서 직접 고른 사진과 문서만 읽습니다.
  • 읽어주기는 기기의 음성(TTS)을 사용하며 마이크를 사용하지 않습니다. 위치, 연락처, 마이크 권한은 사용하지 않습니다.

권한을 거부해도 해당 기능만 쓸 수 없고 나머지는 그대로 동작합니다.

7. 제3자 제공

회사는 사용자의 정보를 수집하지 않으므로 제3자에게 판매하거나 제공하는 정보가 없습니다. 위의 모델 내려받기(Hugging Face)와 결제(Google Play)는 각 서비스 제공자의 약관과 방침이 적용되는 별도의 요청입니다.

8. 데이터 삭제

데이터는 기기에만 있으므로 다음 방법으로 삭제할 수 있습니다.

  • 앱의 설정에서 모든 데이터 지우기를 하면 이 기기의 덱, 카드, 복습 기록, 문서, 퀴즈가 삭제됩니다.
  • 앱을 삭제하면 기기의 앱 데이터가 지워집니다.
  • 기기 자동 백업에 저장된 사본은 기기 설정(Google 계정 백업 관리)에서 삭제할 수 있고, 직접 만든 백업 파일은 파일을 지우면 됩니다.

9. 어린이

앱은 13세 미만 어린이를 대상으로 하지 않습니다. 회사는 어린이를 포함해 누구에게서도 개인정보를 수집하지 않습니다.

10. 방침의 변경

방침이 바뀌면 위의 시행일이 바뀌며, 중요한 변경은 앱 업데이트 노트로 알립니다.
