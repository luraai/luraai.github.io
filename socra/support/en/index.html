Getting started

What is Socra?

A coding practice app with an AI tutor that gives step-by-step hints instead of the answer. Your code runs on the device, so it works offline: Python, JavaScript, SQL, Lua, Ruby and C.

What is the hint ladder?

Five steps: a guiding question, a concept, the place in your code, a small fix, and finally the solution. You open them one at a time. The solution unlocks after a few attempts and a few minutes, so you try first.

Can I ask the tutor anything?

With Pro you can ask free questions about your own work: the tutor reads your problem, your code, the last test result and the console output and explains. Select code in the editor and choose “Ask AI to explain” to ask about just that part. The tutor will not write the full solution for you.

Free and Pro

What is free, and what is Pro?

Free: the first Python units, basic hints, a daily AI hint, 6 algorithm visualizations and 2 AI Lab demos. Pro (one-time purchase, no subscription): every problem and language, all five hint steps, unlimited on-device AI, free questions, all visualizations, unlimited projects with GitHub, pair coding and the full Apple Watch features.

How do I restore my purchase?

Open the Pro screen (the Pro row in the sidebar or Settings) and tap “Restore purchases”, signed in with the same Apple Account.

How do I get a refund?

Purchases are handled by Apple: reportaproblem.apple.com

AI tutor

The AI tutor says it is unavailable.

The built-in tutor needs a device that supports Apple Intelligence, turned on in Settings › Apple Intelligence. On other devices, Pro can download a smaller model in Settings › Tutor. Without a model, the prepared hints for each problem still work. Everything runs on the device.

Is my code sent anywhere?

No. The tutor, the code runner and the visualizer all run on the device. See the Privacy Policy.

Running code

Which parts of C, Ruby and the other languages are supported?

Python is full CPython; JavaScript runs on QuickJS, SQL on SQLite, Lua 5.4, Ruby on mruby 3 (a compact Ruby), and C on a built-in C11 subset interpreter. Settings › About lists what each one supports. No network or file access is available to the code you run.

My program is cut off or too slow.

Runs have time and memory limits to protect your device. Check for an endless loop first. The visualizer can show you what the program is doing step by step.

Devices

Does it work on iPad, Mac and Apple Watch?

Yes. One purchase covers iPhone, iPad and Mac (Apple silicon). The Apple Watch app shows progress and streaks; Pro adds a daily quiz, flashcards and a remote for the visualizer.

How do I pair with a friend?

Pair coding (Pro) works with someone nearby over the local network, or through SharePlay on FaceTime. Allow Local Network access when asked.
