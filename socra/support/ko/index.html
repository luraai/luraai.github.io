시작하기

Socra는 어떤 앱인가요?

정답을 바로 알려 주지 않고 단계별 힌트로 스스로 풀게 돕는 AI 튜터가 있는 코딩 연습 앱이에요. 코드는 기기 안에서 실행되어 오프라인에서도 쓸 수 있어요. Python, JavaScript, SQL, Lua, Ruby, C를 지원해요.

Socra는 무엇이 다른가요?

내 Python 코드가 실행되는 과정을 한 단계씩 보면서, 어느 단계든 튜터에게 물어볼 수 있어요. 튜터는 그 순간의 변수 값을 보고 정답 대신 안내 질문을 해요. 실행 전에 결과를 먼저 예측하고, 내 실수를 모아 보고, 내가 만든 문제를 풀 수도 있어요.

힌트 사다리가 뭐예요?

질문, 개념, 코드의 위치, 작은 수정, 정답까지 5단계예요. 한 단계씩 열 수 있고, 정답은 몇 번 시도하고 몇 분이 지나야 열려요. 먼저 스스로 풀어 보도록 돕기 위한 규칙이에요.

튜터에게 무엇이든 물어볼 수 있나요?

Pro에서는 내 풀이에 대해 자유롭게 질문할 수 있어요. 튜터가 문제, 내 코드, 마지막 테스트 결과와 콘솔 출력을 읽고 설명해 줘요. 에디터에서 코드를 선택하고 “AI에게 설명 요청”을 고르면 그 부분만 물어볼 수 있어요. 튜터는 완성된 정답 코드를 대신 써 주지 않아요.

무료와 Pro

무엇이 무료이고, 무엇이 Pro인가요?

무료: Python 첫 단원들, 기본 힌트, 하루 한 번 AI 힌트, 하루 3번 코드 시각화, 알고리즘 시각화 6개, 내 문제 3개, 실수 노트, AI 랩 체험 2개. Pro(한 번 결제, 구독 없음): 모든 문제와 언어, 5단계 힌트 전부, 온디바이스 AI 무제한, 자유 질문, 모든 시각화, 무제한 내 문제, GitHub 연동이 되는 무제한 프로젝트, 페어 코딩, Apple Watch 전체 기능이 열려요.

구매를 복원하려면 어떻게 하나요?

Pro 화면(사이드바나 설정의 Pro 항목)에서 “구매 복원”을 누르세요. 구매했을 때와 같은 Apple 계정으로 로그인되어 있어야 해요.

환불은 어떻게 받나요?

결제는 Apple이 처리해요: reportaproblem.apple.com

예측, 실수 노트, 내 문제

실행 한 단계를 튜터에게 어떻게 물어보나요?

실행 시각화(또는 내 코드의 “시각화”)를 열고 원하는 단계로 이동한 뒤 “왜 이렇게 움직였나요?”를 누르세요. Python 코드에서 동작해요. 하루 첫 질문은 무료이고, 이어서 묻기는 Pro예요.

“먼저 예측”은 어떻게 동작하나요?

실행 시각화에서 “시각화 전에 결과를 먼저 예측해 보기”를 켜세요. 프로그램이 무엇을 출력할지, 변수 하나가 어떤 값일지 물어본 뒤 실제 실행을 보여 줘요. 어떤 질문이든 건너뛸 수 있어요.

내 실수 노트가 뭐예요?

설정 › 학습 도구 › 내 실수 노트는 틀린 테스트를 유형별로 모으고, 유형마다 일반적인 습관 하나를 알려 줘요. 정답은 알려 주지 않아요. 내가 틀린 예시로 복습 카드도 만들어 줘요. 문제를 통과하면 그 실수는 “고친 실수”로 옮겨져요. 기록은 내 기기에만 있고 언제든 비울 수 있어요.

내 문제는 어떻게 만들거나 가져오나요?

설정 › 학습 도구 › 내 문제에서 제목, 설명, 시작 코드, 내 기준 풀이, 테스트를 적거나 JSON 파일을 가져오세요. 저장하기 전에 내 풀이가 내 테스트를 통과하는지 확인해요. 무료는 Python 문제 3개, Pro는 무제한에 모든 언어예요. 문제를 길게 누르면 내보내거나 삭제할 수 있어요.

AI 튜터

AI 튜터를 쓸 수 없다고 나와요.

기본 튜터는 Apple Intelligence를 지원하는 기기에서 설정 › Apple Intelligence를 켜야 동작해요. 그 밖의 기기에서는 Pro에서 설정 › 튜터에서 더 작은 모델을 내려받을 수 있어요. 모델이 없어도 문제마다 준비된 힌트는 쓸 수 있어요. 모든 처리는 기기 안에서 이뤄져요.

내 코드가 어디로 전송되나요?

어디로도 전송되지 않아요. 튜터, 코드 실행, 시각화가 모두 기기 안에서 동작해요. 개인정보 처리방침을 확인해 주세요.

코드 실행

C, Ruby 등은 어디까지 지원하나요?

Python은 CPython 전체, JavaScript는 QuickJS, SQL은 SQLite, Lua는 5.4, Ruby는 mruby 3(경량 Ruby), C는 내장 C11 부분집합 인터프리터로 실행해요. 언어별 지원 범위는 설정 › 정보에서 볼 수 있어요. 실행하는 코드에서 네트워크나 파일 접근은 할 수 없어요.

프로그램이 중간에 끊기거나 너무 느려요.

기기를 보호하려고 실행 시간과 메모리 제한이 있어요. 먼저 무한 반복이 없는지 확인해 보세요. 실행 시각화로 프로그램이 한 단계씩 어떻게 움직이는지 볼 수 있어요.

기기

iPad, Mac, Apple Watch에서도 쓸 수 있나요?

네. 한 번 구매하면 iPhone, iPad, Mac(Apple 실리콘)에서 모두 쓸 수 있어요. Apple Watch 앱은 진도와 연속 일수를 보여 주고, Pro에서는 데일리 퀴즈, 플래시카드, 시각화 리모컨이 열려요.

친구와 페어 코딩은 어떻게 하나요?

페어 코딩(Pro)은 근처 친구와 로컬 네트워크로, 또는 FaceTime의 SharePlay로 할 수 있어요. 안내가 나오면 로컬 네트워크 접근을 허용해 주세요.
