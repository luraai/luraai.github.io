개인정보 처리방침

시행일: 2026년 10월 12일 · English

Socra에는 계정도, 분석 도구도, 광고도 없어요. 내가 쓴 코드와 튜터와 나눈 대화, 학습 진도는 모두 내 기기 안에만 있어요. 이 앱을 위한 서버를 운영하지 않아서 저희는 그 내용을 볼 수 없어요.

1. 수집하는 정보

LuraAI(이하 “저희”)는 Socra(이하 “앱”)를 통해 개인정보를 수집하지 않아요.

  • 회원가입도 로그인도 없어요.
  • 이름, 이메일, 전화번호, 연락처, 사진, 위치를 묻거나 수집하지 않아요.
  • 분석, 추적, 광고 SDK가 들어 있지 않고, LuraAI로 데이터를 보내는 코드도 없어요.

2. 기기에 저장되는 정보

아래는 사용자가 만들고 기기 안에만 저장되는 정보예요.

  • 직접 쓴 코드, 프로젝트, 푼 문제, 시도 횟수, 사용한 힌트, 연속 학습 일수
  • 문제별로 이어지는 튜터와의 대화
  • 앱 설정, Pro 구매 여부(Apple을 통해 확인)
  • 선택해서 내려받은 AI 모델

앱을 삭제하면 이 정보도 기기에서 함께 지워져요. 코드는 실행을 위해 어디에도 업로드되지 않아요. Python, JavaScript, SQL, Lua, Ruby, C가 모두 앱 안에서 실행돼요.

3. AI 튜터

힌트와 답변은 기기 안에서 Apple의 온디바이스 모델(Apple Intelligence, Foundation Models) 또는 설정에서 직접 내려받은 모델이 만들어요. 코드, 질문, 튜터의 답변은 LuraAI나 클라우드 AI 서비스로 전송되지 않아요. 튜터는 완성된 정답을 그대로 알려 주지 않도록 설계되어 있어요.

4. 네트워크를 쓰는 기능

아래 기능만 인터넷이나 로컬 네트워크를 쓰고, 모두 사용자가 직접 켠 경우에만 동작해요.

기능동작
AI 모델 내려받기 (Pro, 선택)고른 모델 파일을 Hugging Face에서 내려받아요. Hugging Face는 일반 다운로드 요청 정보(IP 주소 등)를 자체 방침에 따라 처리해요. 코드나 대화는 전송되지 않아요.
GitHub 연동 (Pro, 선택)GitHub에 로그인하면 사용자가 푸시하기로 한 프로젝트 파일이 사용자의 GitHub 저장소로 GitHub API를 통해 전송돼요. 로그인 토큰은 기기의 키체인에 저장돼요. 해당 데이터는 GitHub의 방침에 따라 처리되고 저희는 받지 않아요.
페어 코딩 (Pro, 선택)근처 연결은 두 기기를 로컬 네트워크(Bonjour)로 직접 이어 주고, 공유하는 코드와 채팅 메시지는 그 두 기기 사이에서만 오가요. SharePlay는 Apple의 그룹 액티비티 서비스를 써요. AI 내비게이터는 기기 안에서 동작해요.
구매Pro는 한 번만 결제하는 상품이고 결제는 모두 Apple(StoreKit)이 처리해요. 저희는 결제 정보나 Apple 계정 정보를 받지 않아요.
iCloud 진도 동기화 (Pro, 선택, 기본 꺼짐)설정에서 켜면 진도(푼 문제, 시도 횟수, 쓴 힌트 단계, 연습한 날)가 Apple의 iCloud 키-값 저장소를 통해 내 iCloud 계정에 저장되어, 같은 Apple 계정의 기기끼리 맞춰져요. 코드, 풀던 초안, 프로젝트 파일, 튜터 대화는 포함되지 않아요. 이 데이터는 Apple의 방침에 따라 처리되며 LuraAI는 받지 않아요.
Apple Watch진도와 플래시카드는 Apple의 WatchConnectivity로 iPhone과 Apple Watch 사이에서만 오가요. 서버를 거치지 않아요.

5. 기기 권한

로컬 네트워크 권한은 근처 친구와 페어 코딩을 할 때만 요청해요. 카메라, 마이크, 연락처, 사진, 위치는 사용하지 않아요. 권한을 허용하지 않으면 해당 기능만 쓸 수 없어요.

6. 제3자 제공과 판매

수집하는 개인정보가 없으므로 제공하거나 판매할 정보도 없어요. 광고 식별자(IDFA), 쿠키, 앱 간 추적을 사용하지 않아요.

7. 아동

아동을 포함해 누구에게서도 개인정보를 수집하지 않아요. 앱에는 광고도, 공개 피드도, 사용자 생성 콘텐츠도 없어요. 채팅은 페어 코딩에서 함께하는 상대와 나누는 비공개 대화뿐이고, 두 기기 사이에서 직접 전달돼요.

8. 데이터 삭제

앱을 삭제하면 기기에 저장된 모든 정보가 삭제돼요. iCloud로 동기화한 진도는 기기 설정의 Apple 계정 → iCloud → 저장 공간 관리에서 지울 수 있어요. GitHub 연동을 썼다면 GitHub 설정에서 앱의 접근 권한을 취소하고 저장소를 삭제할 수 있어요. 내려받은 모델은 설정에서도 지울 수 있어요.

9. 방침의 변경

방침이 바뀌면 위 시행일이 함께 바뀌고, 중요한 변경은 앱 업데이트 노트로 알려요.
