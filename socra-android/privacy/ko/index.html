Socra 개인정보 처리방침 (Android)

최종 수정일: 2026-10-17

English 한국어

Socra는 Luraai가 만든 오프라인 코딩 연습 앱이에요. 이 문서는 Android 버전(휴대폰, Wear OS)이 데이터를 어떻게 다루는지 알려 드려요. 한마디로 개인 데이터를 수집하지 않아요.

수집하는 정보

없어요. Socra에는 계정, 분석 도구, 광고, 추적이 없어요. 코드, 질문, 학습 진도를 받는 서버도 운영하지 않아요.

기기 안에만 있는 정보

  • 작성한 코드와 초안, 푼 문제, 시도 횟수, 사용한 힌트, 학습한 날
  • 튜터 대화와 설정, 그리고 실행 한 단계에 대해 한 질문(그 단계의 변수 값은 기기 안의 튜터만 읽어요)
  • 내 실수 노트(틀린 테스트를 유형별로 모은 기록, 빗나간 예측)와 "내 문제"에서 직접 만들거나 가져온 문제
  • 직접 만든 프로젝트와 파일
  • 선택해서 내려받은 온디바이스 모델 파일
  • GitHub를 연결한 경우의 토큰: Android Keystore로 암호화해 이 기기에만 저장하고, 백업에서는 제외해요.

코드 실행, 채점, AI 튜터, 시각화는 모두 기기 안에서 동작해요. 코드와 대화는 기기 밖으로 나가지 않아요.

네트워크를 쓰는 선택 기능

직접 사용할 때만, 항상 HTTPS로 통신해요.

  • GitHub (Pro): 프로젝트를 연결·푸시·가져올 때 내 GitHub 계정으로 GitHub와 직접 통신해요. 저희는 그 내용을 볼 수 없어요.
  • 모델 다운로드 (Pro): 다운로드를 누르면 huggingface.co에서 오픈 가중치 모델 파일을 받아요. 일반적인 웹 요청에 담기는 정보(IP 주소 등) 외에 나에 대한 정보는 보내지 않아요.
  • 결제: 일회성 "Pro 평생 이용권"은 Google Play가 결제를 처리해요. 결제 정보는 저희가 받지 않아요.

백업과 내보내기

기기에서 Google 백업을 켜 두면 Android가 Socra의 진도, 프로젝트, 설정을 Google 계정에 백업할 수 있어요. Google의 약관을 따르고 저희는 접근할 수 없어요. Android 파일 선택기로 진도를 직접 내보내고 가져올 수도 있어요. 내 실수 노트와 내가 만든 문제는 Android 백업과 진도 내보내기에 들어가지 않고, 만든 기기에만 남아요. 문제 하나는 직접 JSON 파일로 내보낼 수 있어요.

의견 보내기

설정 > 의견 보내기는 메일 앱을 열고 받는 주소(contact@luraai.io)와 제목에 앱 버전만 채워 줄 뿐이에요. Socra가 스스로 보내는 것은 없고, 무엇을 보낼지는 내가 정해요.

근처 친구와 페어 코딩

같은 Wi-Fi에서 두 기기가 직접 연결돼요. 공유하는 코드와 채팅은 내가 허락한 상대 기기로만 가고 저희에게는 오지 않아요. AI 페어는 기기 안에서 동작해요.

Wear OS

워치 앱은 진도와 퀴즈 상태를 워치에 저장하고, Google의 Wearable Data Layer로 폰과 동기화해요. 센서와 위치는 쓰지 않아요.

어린이

Socra는 만 13세 미만 어린이를 대상으로 만들지 않았고, 개인 정보를 알고서 수집하지도 않아요.

데이터 삭제

앱 설정에서 진도 초기화, 프로젝트 삭제, 모델 삭제, 실수 노트 비우기, 내 문제 삭제를 하거나 앱을 삭제하면 돼요. 서버에 저장한 데이터가 없어서 따로 지울 것은 없어요. Google 백업은 Google 계정의 백업 설정에서 지울 수 있어요.
