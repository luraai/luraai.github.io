Socra is an offline coding practice app with an on-device AI tutor. Need help? Write to contact@luraai.io and include your device model, Android version and app version.

Getting started

  1. Open a problem on the Practice or Learn tab, write your code and tap Run.
  2. Stuck? Tap Hint. The tutor gives a question first, then the concept, the place in your code and a small fix. The solution opens after a few tries.
  3. Use Templates to watch algorithms run step by step, or run your own code in the visualizer.

Free and Pro

Free: the first two Python units (10 problems), basic hints, one AI hint per day, 6 visualizations and 2 AI Lab demos. Pro Lifetime is a one-time purchase (not a subscription) that opens everything. Restore it on the purchase screen if you reinstall or change device (same Google account).

Frequently asked questions

Does it need internet? No. Running code, the tutor and the visualizer work offline. Internet is only used for optional GitHub sync, optional model downloads and Google Play purchases.

Which AI does the tutor use? Gemini Nano (AICore) on supported devices. On other devices it uses an optional downloadable on-device model (Settings > AI tutor) or the prepared step-by-step hints.

Which languages run? Python, JavaScript, SQL, Lua, Ruby (mruby) and C (a C11 subset interpreter). Some advanced language features are not available.

Where is my data? Only on your device. See the privacy policy.

Nearby pair coding does not find my friend. Both devices must be on the same Wi-Fi network without client isolation, with Socra open on the Pair screen.

Wear OS app. Install it from Google Play on your watch. It works on its own; connect it to the phone app to sync progress and use the remote.

Refunds. Handled by Google Play according to its refund policy.
